# jawwaad — personal site

A static site: `index.html`, `styles.css`, three small scripts. No framework, no build step.

## Preview locally

```powershell
cd "C:\Users\jawwa\OneDrive\Desktop\portfolio"
python -m http.server 8731
```

Then open http://127.0.0.1:8731. (Opening `index.html` straight from disk also works.)

## Before each deploy

Refresh the bundled element sets so the sky plot starts from fresh orbits:

```powershell
python tools\build_tles.py            # from SatelliteDashboard's cache
python tools\build_tles.py --fetch    # or straight from CelesTrak
```

The watch list is read from `..\SatelliteDashboard\config.py`, so adding a
satellite there adds it here. If the bundle goes stale (over 5 days), the page
pulls fresher sets from CelesTrak itself and caches them for 12 hours; offline,
it keeps the bundle and says how old it is.

## Deploy

Any static host works. Two with zero config:

- **GitHub Pages:** push this folder to a repo, then Settings → Pages → deploy from `main` / root.
- **Vercel:** `vercel deploy` from this folder (you already use it for ASCEND).

## What lives where

| File | What it does |
|---|---|
| `index.html` | All the content. Every number on the page traces to a project. |
| `styles.css` | Tokens at the top: light (day shift) and dark (night shift). One accent, the highlighter. |
| `js/sky.js` | SGP4 propagation from the station's coordinates, pass prediction, the polar plot. |
| `js/main.js` | Theme toggle, the evidence grid, the element-set signature in the footer. |
| `js/tles.js` | Generated by `tools/build_tles.py`. Don't edit by hand. |
| `assets/` | The résumé PDF linked from the page (currently the general, no-CGPA version). |

Station constants (12.9500° N, 77.6670° E, 888 m, 25° floor) are at the top of
`js/sky.js` and must match the station's Gpredict QTH, same as the dashboard.
